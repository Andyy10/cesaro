## Acerca de
Elaborado como un pequeño experimento, este descifrador es capaz de encriptar y desencriptar mensajes usando la terminal, siempre que se le proporcione el mensaje original y la cantidad de veces que se tiene que mover en el abecedario.

## Dependencias
* Python 3.14.7

## Uso
1. Descargar la versión más reciente de [Python](https://www.python.org/downloads/).
2. Clonar el repositorio.
```
git clone https://github.com/Andyy10/cesaro.git
```
3. En una terminal (CMD, Terminal, Powershell) ejecutar el archivo main.py que se encuentra en la carpeta 'src'.
```
cd src
python main.py
```
4. Ingresar qué se quiere hacer (cifrar o descifrar), el texto original y la cantidad de veces que se tiene que mover en el abecedario.

## Estructura del proyecto
```text
cesaro: Descifrador César CLI.
├── src: Archivos necesarios para que el proyecto funcione.
│   ├── main.py: Programa principal donde se maneja la lógica del juego.
│   └── arte_cesaro: Módulo donde se tiene el logo del programa como arte ASCII.
└── docs: Documentación del proyecto e imágenes.
```
